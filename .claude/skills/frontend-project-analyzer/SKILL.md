# 一、项目整体概述（面试开场白专用）
1. 项目定位、业务场景、核心能力
2. 完整技术栈（前端/AI能力/后端接口/工程化）
3. 个人负责模块与核心职责（可直接面试口述、写简历）

# 二、核心技术知识点（分层梳理，适配中高级）
分模块整理，每个知识点附带面试可背诵精简解释：
1. 前端框架核心知识点（Vue3/React 高级特性）
2. 工程化与性能优化知识点
3. 状态管理、路由、权限体系知识点
4. 网络封装、请求拦截、并发处理知识点
5. AI专属知识点（AI对话、RAG知识库、向量库、大模型对接、流式输出、Agent工具调用）
6. 组件封装、复用、抽象设计知识点
7. 部署、适配、兼容性知识点

# 三、项目完整业务逻辑与执行流程（面试官必问）
1. 项目启动加载全流程
2. 权限校验、路由跳转、页面渲染流程
3. 普通业务数据流转逻辑
4. AI核心业务流程（提问-检索-调用工具-流式返回-结果渲染）
5. 全局通用机制（拦截器、全局组件、钩子、状态更新）

# 四、项目优缺点 + 优化方案（中高级核心加分项）
✅ 项目优势（分架构设计、工程规范、性能体验、AI能力、复用性、可扩展性6个维度，适配大厂评审标准，可直接写简历）
❌ 项目现存不足（真实落地问题，拒绝空洞描述）
💡 可落地优化方案（给出具体改造思路、技术方案、优化收益，面试高频考察）

# 五、分梯度面试真题+标准答案（通吃大小厂）
区分三个梯度，精准匹配岗位：
1. 小厂基础题：业务落地、功能实现、基础技术使用
2. 中厂进阶题：项目难点、问题排查、性能优化、业务解决方案
3. 大厂深度题：原理深挖、架构设计、选型对比、瓶颈分析、高并发、AI架构设计
每道题固定格式：【面试原题】+【标准口述答案（精简版）】+【加分话术/避坑点】

# 六、简历专属项目描述（一键复用）
输出1段精简版、1段高阶版项目经历，适配中高级、AI岗简历投递。

【严格约束规则】
1. 所有分析必须贴合用户提供的项目信息，不能凭空编造无关技术点；
2. AI相关岗位重点突出：RAG、向量库、Agent、工具调用、流式渲染、大模型对接、Prompt工程；
3. 中高级前端岗位重点突出：工程化、性能优化、组件抽象、权限架构、封装思想、线上问题复盘；
4. 全部答案口语化，适合面试口述，拒绝大段学术书面空话；
5. 大小厂分层出题，匹配不同面试难度；
6. 所有优化方案必须可落地，符合企业真实开发场景。
